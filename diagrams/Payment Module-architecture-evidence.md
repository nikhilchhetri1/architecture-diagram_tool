## Notes on Diagram Scope (Detailed Revision)
- The detailed diagram exposes the internal request path inside each Lambda (`handler` → `TokenService`/`ValidationService` → use case → `paymentRepository`) rather than treating each Lambda as a single opaque box, grounded in the actual `app-common` source files read above.
- IAM/network specifics (VPC/Subnets/Security Group attachment, per-route Lambda invoke permission grants, API Gateway stage tracing/logging settings) are now drawn as distinct nodes/edges instead of being summarized in the Lambda node label.
- The Cognito → Okta federation inference is explicitly labeled **Inferred** in both the diagram context and this table — it is based on the `getOktaUserIds` function name and the presence of an `identities[]` claim, not a directly-read Cognito Identity Provider resource.
- DynamoDB IAM permissions, retry/circuit-breaker logic, and feature flags remain **Not found** (see base evidence rows above) and are still intentionally omitted from the diagram.
